

## Winding
Need some practical way to wind the wires.
Multiple designs are common.

- Winder integrated in center isolator
- Winders for each side, integrated in side/end isolators.

## Balun

A 1:1 balun is commonly used. Recommended when transmitting.
But one can make-do without it.

## End isolators

## Linked dipoles

One can take the insulators and make them possible to link across with a.
This allows extending a base inverted V dipole with longer arms,
and create a multi-band capable system.
Can use alligator clips or similar quick-connect plugs.

- [A Linked Dipole for POTA Activations](https://www.onallbands.com/ham-radio-portable-insights-a-linked-dipole-for-pota-activations/).
Showing example of a 40/30/20M linked dipole. Used 18 AWG silicone wire.
